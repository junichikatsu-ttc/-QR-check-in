# 運用

## 当日の流れ

1. 先生が `teacher.html` でログイン（共通パスワード + 自分の表示名）
2. **名簿** が未登録なら、Excel から「学籍番号・氏名・クラス」を貼り付けて保存
3. **イベント** を作る（例: 「10/8 帰りのバス」、対象クラスを選ぶ）
4. スキャン画面で「読み取り地点」に自分のバス番号を入れる（端末に記憶される）
5. 生徒は `index.html`（トリガーの URL）で学籍番号を入れて QR を出す
6. 先生が QR を読む。音と振動で成功、画面に氏名が出る。**済みの生徒を再度読むと黄色で「済み」と出る**
7. **一覧** タブで未チェックインを確認。QR を出せない生徒は「手動」で学籍番号入力
8. 必要なら **CSV** で書き出し（学籍番号・氏名・クラス・状態・時刻・地点・方法・担当）

## 環境変数（関数側）

| 変数 | 必須 | 既定 | 説明 |
| :--- | :--- | :--- | :--- |
| `SESSION_SECRET` | ✓ | — | ログインと QR の署名鍵。32 文字以上のランダム文字列。**変えると全員ログアウト** |
| `TEACHER_PASSWORD` | ✓ | — | 先生の共通パスワード |
| `DS_TABLE_ROSTER` / `DS_TABLE_EVENTS` / `DS_TABLE_CHECKINS` | ✓ | — | テーブル ID |
| `QR_TTL_SEC` | | 300 | QR の有効秒数 |
| `SESSION_TTL_HOURS` | | 168 | ログインの有効時間 |
| `EVENT_LIST_LIMIT` | | 50 | イベント一覧の件数 |
| `TENANT_ID` | | default | 学校の識別子 |
| `LOG_LEVEL` | | INFO | DEBUG 以上にしない（入力内容がログに出うる） |
| `BASIC_AUTH_USER` / `BASIC_AUTH_PASSWORD` | | — | 両方そろえば HTML 全体に BASIC 認証が掛かる（任意） |

不足は `/v1/health` の `configOk: false` と `configMissing`（件数）で分かる。キー名は実行環境の起動ログに出る。

## データストアのアクセス数の目安

enebular データストアには月次のアクセス上限がある（フリー 10,000 / エンタープライズ 3,000,000）。
1 回の引率（生徒 160 人、先生 4 人、バス 4 台、往復 2 イベント）での概算:

| 操作 | 回数 | アクセス |
| :--- | ---: | ---: |
| 生徒ログイン（名簿 getItem。キャッシュ命中は 0） | 160 | ≈ 40 |
| スキャン（getItem + putItem） | 320 | 640 |
| 一覧の表示（160 人 → query 2 ページ）先生 4 人 × 2 イベント × 30 分 / 30 秒 | 480 | 960 |
| イベント作成・名簿保存 | 3 | 3 |
| **合計** | | **≈ 1,650** |

一覧の自動更新（30 秒）が最も大きい。節約したいときは一覧タブを開きっぱなしにせず、
スキャン画面に戻しておく（スキャン画面では query しない）。
フリープランで月 10,000 なら、この規模の引率が月 5〜6 回まで。

## 名簿の更新が反映されるまで

名簿は実行コンテナ内で 30 秒キャッシュされる。保存した直後に別のコンテナが処理したリクエストでは
最大 30 秒古い名簿が見える（新しく追加した生徒がログインできない）。少し待って再試行すればよい。

## QR の有効期限

既定 5 分。生徒の画面は期限の 20% 手前で自動的に取り直すので、画面を開いたままなら切れない。
バックグラウンドに回っていた場合は、画面に戻った瞬間に取り直す。
先生側で「QR の有効期限切れ」と出たら、生徒に「更新」を押してもらう。

## 不正への耐性

| できること | できないこと |
| :--- | :--- |
| QR の偽造（署名が要る） | 他人の学籍番号でログインする（学籍番号しか聞かないため） |
| スクリーンショットの使い回し（5 分で失効） | 先生が本人確認をせずに読み取る |
| 先生 API を生徒トークンで呼ぶ（403） | 共通パスワードが漏れた場合の先生なりすまし |

学籍番号でのなりすましを防ぎたい場合は、名簿に第 2 要素（生年月日など）の列を足して
`POST /v1/auth/student` で突き合わせる。

## 切り分け

| 症状 | 見るところ |
| :--- | :--- |
| デプロイしたのに画面が変わらない | `/v1/health` の `commit`。HTML の `app.js?v=` が新しい値か |
| カメラが起動しない | https で開いているか。ブラウザのカメラ許可。iOS は Safari（アプリ内ブラウザは不可のことがある） |
| 「この学籍番号は名簿にありません」 | 名簿が保存されているか（先生画面の「名簿: N 人」）。保存直後なら 30 秒待つ |
| `configOk: false` | 実行環境のログに不足キー名。`npm run enebular:config` の `FN_*` |
| 503 `DATASTORE` | テーブル ID と `connectDataStore`。`details.operation` / `kind` で操作と種類が分かる |
| `/qr-checkin/...` が全部 404 | トリガーのパスがインスタンス内で一意か。404 の本文に受け取ったパスが出る |
